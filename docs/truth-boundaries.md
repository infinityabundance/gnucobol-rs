# Truth boundaries — bytes / record / posting / accounting / extraction / business

> _Generated document (TRUST.4.DOCS). Machine authority: `reports/claim-ladder.json` + `reports/casefiles/`. Born generated (no legacy source)._

> **KOBOLD does not turn COBOL data into truth. It turns legacy bytes into accountable evidence under
> declared courts, profiles, and refusals.**

> _Bytes are not record truth; record truth is not posting truth; posting truth is not accounting truth;
> accounting truth is not extraction truth; extraction truth is not business truth._ This stack proves the
> **lower** rungs and **refuses to cross** the upper ones unless an explicit, declared reconciliation
> profile admits it. Banking COBOL data is not merely decoded; it is reconciled under declared control
> boundaries.

## The truth hierarchy

| level | question it answers | who admits it |
|-------|---------------------|---------------|
| **bytes** | what are the raw bytes, at what offset? | `KOBOLD.FILE.1` ingest + raw_hex (proven) |
| **record truth** | what does *this copybook* say these bytes mean? | the sealed `gnucobol-rs` courts (proven) |
| **posting truth** | which records form a balancing/settlement unit? | `KOBOLD.POSTING.1` + a declared manifest (future) |
| **accounting truth** | debit/credit polarity, amount-vs-rate role, currency minor units | `ACCOUNTING.PROFILE.*` (future) |
| **extraction truth** | is this the live state, or an as-of/EOD extract? | `EXTRACT.ATLAS.1` (future) |
| **business truth** | is the value lawful, complete, current, and correct for the business? | **never** — outside the project |

The stack today proves **bytes** and **record truth**. Everything above is **refused by default** — see the
machine-readable registry [`reports/negative-capabilities.json`](../reports/negative-capabilities.json).

## What we refuse to infer (banking operating semantics)

Each is registered as a negative capability and admitted only by an explicit declared profile:

- **`NEG.ACCOUNTING.POLARITY`** — debit/credit is not inferred from sign / `CR`·`DB` / transaction code / account type.
- **`NEG.NUMERIC.ROLE`** / **`NEG.IDENTIFIER.NUMERIC_COERCION`** — a numeric field is not assumed to be an *amount*; `PIC 9` identifiers stay strings (leading zeros are material).
- **`NEG.DATE.INFERENCE`** — `PIC 9(8)` is numeric text, not a date or a format.
- **`NEG.CURRENCY.SCALE`** — `V99` proves copybook scale, not currency minor-unit correctness.
- **`NEG.FIGURATIVE.SENTINEL`** — `LOW-VALUES`/`HIGH-VALUES`/`ZEROES`/`SPACES` are preserved as bytes, never given sentinel meaning.
- **`NEG.DB2.NULL.INDICATOR`** / **`NEG.SQL.PRECOMPILER`** — a clean decode is not DB2 null-state truth; COPY/layout is not Db2 precompiler transformation.
- **`NEG.CICS.MESSAGE.SCHEMA`** / **`NEG.CICS.HANDLE.CONTROL`** — a copybook over COMMAREA/channel data is not a file schema; no CICS control-flow is inferred from data.
- **`NEG.POSTING.UNIT`** / **`NEG.BATCH.CONTROL.UNDECLARED`** — records are not grouped into a balancing unit, and a `FILE.1` record count is not a banking batch control total, without a declared manifest.
- **`NEG.SINGLE_LAYOUT_ASSUMPTION`** — one layout is not assumed per file when records carry a header/detail/trailer discriminator.
- **`NEG.NUMERIC.ENVIRONMENT.UNKNOWN`** / **`NEG.SIZE_ERROR.SEMANTICS`** — no transformed-record write-back outside the admitted numeric environment (`ARITH`/`TRUNC`/sign mode) or without admitted `ON SIZE ERROR` semantics.
- **`NEG.REVERSAL.INFERENCE`** — a reversal is not inferred from a negative sign alone.
- **`NEG.CURRENTNESS`** — decoded bytes are an extract, not proven to be the current live banking state.
- **`NEG.PUBLIC.CUSTOMER.DATA`** — public casefiles/audits carry synthetic data only; never real customer/account/PII.

## Why this is the senior distinction

The dangerous failure in a banking migration is not an exception — it is a **plausible wrong decode promoted to truth**: a numeric field summed as money, a sign read as debit/credit, a clean value that is actually `NULL`, an EOD extract acted on as live state. This court's value is that every supported surface is *admissible evidence at a named truth level*, and every higher level is an explicit refusal until a profile admits it.
