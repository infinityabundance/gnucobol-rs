# Porting method (oracle-first, receipt-first, fail-closed)

> _Generated document (TRUST.4.DOCS). Machine authority: `reports/claim-ladder.json` + `reports/casefiles/`. Legacy source preserved losslessly under `research/legacyreports/docs/porting-method.md`._

A self-contained restatement of the method `gnucobol-rs` follows for every sealed slice. The
order is not negotiable: the oracle exists **before** the port, so "correct" can only ever
mean "matches the oracle."

## The phases, in order

1. **Admit.** Pin the exact upstream release by sha256 (`research/gnucobol-3.2.tar.lz`).
   Record the GnuCOBOL version, the build command, the resulting `cobc`/`libcob` sha256, the
   compiler (`gcc`) and `gmp` versions, and the pinned env. Never vendor the bytes into a
   published crate — gitignore them, re-fetchable.
2. **Read.** Read the upstream source completely before writing Rust — the entry points, the
   dispatch, the helper macros, the byte/return semantics. (For the decimal slice:
   `libcob/move.c`, `libcob/numeric.c`, `libcob/common.c`, `libcob/coblocal.h`, `libcob/common.h`.)
3. **Build the oracle.** Compile the real upstream into `lab/oracle/prefix`. This — not our
   reading — is the source of truth. Two oracle shapes are used:
   - a **program oracle** (`cobc -x prog.cob`, run, capture stdout/stderr/exit + hashes), and
   - a **runtime-library oracle**: a tiny C harness that links the built `libcob`, constructs
     `cob_field`s, calls the real `cob_move`/packed helpers, and dumps raw field bytes. This
     **decouples** the unit under test from the compiler front-end.
4. **Port faithfully, with citations.** Mirror upstream control flow, not just outputs. Cite
   the upstream line for each ported block (`// move.c:477`). Reproduce quirks, padding, and
   undefined-but-observed choices exactly.
5. **Prove parity.** Feed identical input rows to the C oracle and a Rust `examples/rows`
   mirror; compare **full byte streams** (never `$(...)`-captured — it strips trailing
   newlines; never naive line-zip when payloads embed newlines).
6. **Fixtures.** Commit `(input, expected)` pairs — `expected` generated by the real oracle —
   for branches the canonical rows miss, so `cargo test` passes with `lab/` absent.
7. **Sweep.** Exhaustive over the small type/PIC matrix, differential over thousands of random
   valid + invalid `(PIC, value)` cases. Print `PASS=n FAIL=0` with classified-out counts
   shown **separately** — never hidden inside the pass count.
8. **Kani.** Prove one sharp reduced-surface invariant (an index/arithmetic bound), bounded
   with `kani::assume` + `#[kani::unwind]`. A non-convergent harness is a harness-design
   failure, not a verdict, and never appears on the result surface.
9. **Fuzz.** A detached fuzz crate over the hostile byte/attr surface; fix every panic with
   checked/saturating arithmetic or a typed reject (the way the oracle rejects), commit each
   crash as a regression seed, record the run counts.
10. **Gate & seal.** `cargo fmt --check`; `cargo clippy --all-targets -D warnings`; tests; the
    oracle sweep; fuzz smoke; no `lab/`/`reports/`/`fuzz/` leakage in `cargo package --list`.
    Ship the receipts in the same commit.

## Knowing a libcob file is _done_ (the doxygen C-vs-Rust diff)

A function-for-function port needs an authoritative answer to "did we miss a function?". The
line-based name inventory (`LIBCOB-PARITY.md`) can miss comment-decorated or macro-wrapped
signatures, so the **authoritative** inventory comes from **doxygen's preprocessed C parse** of the
pinned libcob:

- `doxygen lab/doxygen/Doxyfile-c-xml` emits a machine-readable `<memberdef kind="function">` list
  per `libcob/*.c` (XML-only, ~0.2 s; `EXTRACT_ALL`/`EXTRACT_STATIC`, GMP path predefined).
- `cargo run -p xtask -- doxygen-compare generate` (Rust, not Python) cross-checks every doxygen
  function against `crates/gnucobol-rs/src` and writes `DOXYGEN-PARITY.md` +
  `reports/doxygen-parity.json`. A file is **done** only when its `missing` list is empty.
- `doxygen-compare check` is the gate — anti-staleness (regenerate-and-diff) plus a hard
  "did we miss anything" failure if any file the awk parity calls complete still has a
  doxygen-found function with no Rust counterpart. It runs in both `lab/verify-sealed-courts.sh`
  and the docs staleness gate `lab/check-docs.sh`. Regenerate everything with
  `bash lab/doxygen/refresh-rust.sh`.

## Non-negotiable disciplines

- **Faithful, not improved.** A nicer divergence is a bug.
- **Fail closed.** Malformed/oversized input is a typed `Err`, never a panic, OOB, or overflow.
- `#![forbid(unsafe_code)]`; `overflow-checks = true` in release; MSRV pinned.
- **Zero runtime deps where practical** — hand-write the small nibble logic rather than pull a
  crate; a dependency enlarges the audit surface and can *change* behavior.
- **Additive, never narrowing.** Receipts cite each other; nothing is "done" without a receipt;
  every audit names the lie it prevents.
