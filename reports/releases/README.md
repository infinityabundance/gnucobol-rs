# Release evidence packets (ENTERPRISE.1)

> **Doctrine.** ENTERPRISE.1 treats a release as an evidence packet, not merely a version number: every
> published crate version is accompanied by reproducible receipts, dependency/license inventory, feature
> flags, audit status, claim boundaries, negative capabilities, and a release verdict that refuses to
> overstate production readiness.

Each `reports/releases/<crate>-<version>/` is generated by `lab/release/build-packet.py` and contains:

| file | proves |
|------|--------|
| `release-verdict.md` | human summary, generated from the machine files below |
| `release-metadata.json` | crate, version, git commit, publish status, dependency count |
| `sbom.spdx.json` | SPDX software inventory (derived from `cargo metadata`) |
| `licenses.json` | dependency license summary + the LGPL/GPL/Apache boundary |
| `feature-matrix.json` | features + which are default (off-by-default stays boring) |
| `cargo-audit.txt` | advisory check result, or honest unavailable status |
| `cargo-geiger.txt` | unsafe status (every shipped crate is `#![forbid(unsafe_code)]`) |
| `receipt-manifest.json` | the TRUST.2 generated receipts this release stands on |
| `claim-ladder-snapshot.json` | the claim ladder (this crate's courts) at release time |
| `negative-capabilities-snapshot.json` | the non-claims (+ lie_prevented) at release time |
| `status-snapshot.md` | a copy of STATUS.md at release time |

**Honest statuses only** — tools that cannot run are marked `not_installed` / `not_run` /
`network_unavailable`, never faked green. Regenerate: `python3 lab/release/build-packet.py <repo> <crate>
<version> <gnurust|kobold>`.
